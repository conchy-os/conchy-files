# conchy-files

Файловый менеджер для **Conchy OS**: интерфейс и поведение Thunar, переписанные на Rust и [GPUI](https://www.gpui.rs/), плюс анализ занятого места (treemap и типы файлов, как в WizTree).

> Статус: этапы 1–6 переноса Thunar реализованы (см. [docs/thunar-port.md](docs/thunar-port.md)). Не сделаны вкладки, зашифрованные разделы и хранение паролей сети; сетевые адреса проверены только тестами (нет `sshfs`/`rclone` на машине разработки).

## Возможности

- **Окно как у Thunar.** Кнопки «назад», «вперёд», «вверх», «домой»; путь кнопками, по `Ctrl+L` — поле ввода с дополнением по `Tab`. Боковые кнопки мыши тоже листают историю.
- **Боковая панель.** «Места»: домашняя папка, рабочий стол, корзина, закладки GTK (общие с Thunar и Nautilus), иначе XDG-папки. «Устройства»: файловая система, флешки, диски и образы через UDisks2 с полоской занятого места. Неподключённое показано бледным — щелчок подключает и открывает; у съёмных кнопка ⏏ «Безопасно извлечь», по правому щелчку — меню. Список обновляется сразу, когда устройство вставили или вынули. Об извлечении сообщает системное уведомление (в Conchy OS — conchy-shell).
- **Список.** Колонки «Имя», «Размер» (у папок — число элементов), «Тип» (описание из shared-mime-info), «Изменён» («Сегодня, 10:41»). Сортировка щелчком по заголовку, папки сверху, естественный порядок чисел. Иконки из темы freedesktop. Скрытые файлы по `Ctrl+H`, поиск по первым буквам.
- **Живое обновление.** Папка перечитывается через inotify, когда в ней что-то меняется.
- **Корзина** по спецификации freedesktop: та же, что у Thunar и `gio trash`. Восстановление, удаление насовсем, очистка.
- **Операции, как в Thunar.** Копировать, вырезать, вставить, переименовать, создать папку или файл, в корзину, удалить насовсем. Отмена через `Ctrl+Z`. Конфликты имён: заменить, пропустить, переименовать, объединить папки, «для всех». Операции идут в фоне с прогрессом и отменой.
- **Контекстные меню** для файлов и для пустого места, выделение `Ctrl`/`Shift`+щелчком, «Открыть терминал здесь».
- **Открыть с помощью.** Двойной щелчок открывает программой по умолчанию из `mimeapps.list` (не через `xdg-open`). В меню — «Открыть в «Программа»», ещё пара подходящих и «Открыть с помощью другой программы…» с поиском и флажком «Всегда открывать этой программой» (правит `~/.config/mimeapps.list`, как `xdg-mime default`).
- **Поиск** `Ctrl+F` по имени в текущей папке и вложенных: подстрока или шаблон (`*.pdf`), находки появляются по мере обхода, вместо «Типа» — где лежит. `Esc` — обратно к папке.
- **Виды** «Значки», «Подробно», «Компактный» (`Ctrl+1/2/3`). В виде значков у картинок миниатюры из общего кеша freedesktop (`~/.cache/thumbnails`, тот же, что у Thunar и Nautilus).
- **Перетаскивание** на папку, пустое место, «Места», устройства и корзину. Внутри раздела — перенос, между разделами — копия; `Ctrl` — копировать, `Shift` — перенести. Файлы из других программ принимаются копированием.
- **Повтор** отменённого: `Ctrl+Shift+Z` или `Ctrl+Y`.
- **Права** в свойствах файла: владелец, группа, остальные × чтение, запись, запуск; у своих файлов меняются щелчком.
- **Пользовательские действия** из `files.kdl` в контекстном меню (как Custom Actions в Thunar), см. «Настройки».
- **Сеть через FUSE.** В строку пути: `sftp://user@host/папка` (через `sshfs`: ключи и агент, при отказе — запрос пароля), `smb://host/общая`, `ftp://`, `dav://`, `davs://` (через `rclone`). Подключённое — в разделе «Сеть» с кнопкой отключения. Пароли не сохраняются.
- **Одиночный экземпляр.** Пока открыто окно, новые запуски и «Показать в папке» (`org.freedesktop.FileManager1`) открывают окна в том же процессе — мгновенно. Последнее окно закрыто — процесс завершается и освобождает память.
- **Нижняя панель** (`Ctrl+I`, кнопка справа на панели инструментов, `Alt+Enter` — «Свойства»):
  - папка или диск — treemap (площадь = размер, цвет = тип), типы файлов, самые крупные файлы; для раздела — устройство, ФС, занято и свободно. Щелчок по ячейке показывает, что это; двойной — открывает папку или показывает файл в списке;
  - файл — свойства (точный размер, место на диске, права, владелец, даты, цель ссылки) и предпросмотр картинки или начала текста.

  Сканируется текущая папка, одно дерево обслуживает все подпапки. После копирования или удаления дерево обновляется точечно, а не пересканируется. Результаты долгих сканирований сохраняются в `~/.cache/conchy-files` и переживают закрытие окна и перезагрузку: при следующем открытии карта появляется сразу с пометкой «данные от …», а в фоне перепроверяется только открытая папка. Пока анализ есть, в колонке «Размер» у папок стоит их настоящий размер. Край панели можно тянуть; высота и видимость запоминаются в `files.kdl`.

## Скорость анализа

Сканер для нижней панели. Домашняя папка: 867 тыс. файлов, 96 тыс. папок, 194 ГБ, NVMe.

| | Время |
| :--- | :--- |
| `conchy-files`, первый запуск (холодный кеш) | 5.9 с |
| `conchy-files`, повторный запуск | 0.4 с |
| `du -sx ~`, повторный запуск | 1.8 с |

Замерить у себя: `cargo run --release --example scan_bench -- ~/`

Кеш анализа (та же домашняя папка, 581 тыс. файлов): 7.7 МБ на диске, загрузка 0.2 с. Пересканирование, пока метаданные в памяти ОС, — 0.53 с; после перезагрузки — секунды. Замерить: `cargo run --release --example cache_bench -- ~/`

Кеш лежит в `~/.cache/conchy-files/trees` (скрытая папка), одна запись на просканированную папку, имя файла — хеш UUID раздела и пути. Файлы доступны только владельцу (0600).

На диск пишутся только деревья, которые долго пересчитывать (сканирование от 1 с или от 20 тыс. файлов), и только изменившиеся: сканирование, перепроверка или операция с файлами помечают дерево, а запись идёт одна, через 10 секунд тишины. При закрытии окна недописанное сохраняется сразу.

Кеш не копится:

- при запуске удаляются записи пропавших папок, испорченные и не открывавшиеся `max-age-days` дней;
- при сохранении дерева удаляются записи вложенных папок того же раздела — они уже внутри него;
- всё сверх `max-size-mb` вытесняется, начиная с давно не открывавшихся;
- `enabled false` удаляет кеш целиком.

Посмотреть, что в кеше: `cargo run --release --example cache_info`.

## Сборка и запуск

Нужны Rust (stable) и системные библиотеки для GPUI: `wayland`, `libxkbcommon`, `libxcb`, `fontconfig`, `freetype2`, `vulkan-icd-loader`, а также `clang` и `cmake`.

```bash
git clone https://github.com/conchy-os/conchy-files.git
cd conchy-files
cargo run --release -- ~/Документы   # папка или файл; по умолчанию домашняя
```

Чтобы conchy-files стал файловым менеджером по умолчанию и отвечал на «Показать в папке» из браузера:

```bash
install -Dm755 target/release/conchy-files /usr/bin/conchy-files
install -Dm644 data/conchy-files.desktop /usr/share/applications/conchy-files.desktop
install -Dm644 data/org.freedesktop.FileManager1.service /usr/share/dbus-1/services/org.freedesktop.FileManager1.service
xdg-mime default conchy-files.desktop inode/directory
```

Для сетевых адресов нужны `sshfs` (SFTP) и `rclone` (SMB, FTP, WebDAV) — необязательные зависимости.

В `Cargo.lock` зафиксирована `libc` 0.2.188: крейт `xattr` 0.2.3, который тянет GPUI 0.2.2, не собирается с `libc` 0.2.191. Не запускайте `cargo update` целиком, обновляйте пакеты по одному.

## Настройки

conchy-files входит в единый KDL-конфиг Conchy OS ([conchy-config](https://github.com/conchy-os/conchy-config)), канал `files`: файл `~/.config/conchy/files.kdl`. Он создаётся при первом запуске с комментариями; другие файлы (`wm.kdl`, `session.kdl`) программа не трогает.

```kdl
view {
    show-hidden false        // Ctrl+H; conchy-files saves it here
    folders-first true
    sort-by "name"           // name, size, type, modified
    sort-order "ascending"   // ascending, descending
    folder-size "items"      // items: "12 items"; none: faster on huge folders
}
window {
    width 1100
    height 720
    sidebar-width 210
}
terminal {
    command ""               // "Open Terminal Here"; empty: $TERMINAL or auto
}
theme {
    icon-theme ""            // empty: same as GTK apps
    font-size 13
}
panel {
    visible false            // Ctrl+I; saved here
    height 300               // drag the panel edge; saved here
}
cache {
    enabled true             // false deletes ~/.cache/conchy-files
    max-size-mb 100
    max-age-days 30          // entries not opened this long are removed
}
```

- Изменения применяются сразу, без перезапуска: правка в редакторе, `conchy-config set files view.sort-by size` или любой настройщик через D-Bus `org.conchy.Config`.
- Окно само запоминает `Ctrl+H` и сортировку по щелчку на заголовке. Запись идёт через демон, чтобы остальные программы получили `PropertyChanged`; если демон не запущен — прямо в файл, комментарии сохраняются.
- Ошибка в файле не ломает окно: остаются прежние настройки, в строке состояния видно, что не так.

Пользовательские действия — блок `actions` в том же файле (подстановки как в Thunar: `%f` первый путь, `%F` все, `%d`/`%D` папки, `%n`/`%N` имена; всё в кавычках оболочки):

```kdl
actions {
    action "Открыть в VS Code" {
        command "code %F"
        directories true
        background true      // и в меню пустого места — для текущей папки
    }
    action "Уменьшить вдвое" {
        command "magick %f -resize 50%% %d/small-%n"
        types "image/*"      // MIME-шаблоны; без types — любые файлы
    }
}
```

Для сборки `conchy-config` должен лежать рядом: `../conchy-config`.

## Клавиши

Как в Thunar 4.20.

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓`, `Shift+↑` / `Shift+↓` | Перемещение и расширение выделения |
| `Home` / `End`, `PageUp` / `PageDown` | В начало / конец списка, на страницу |
| `Enter`, двойной щелчок | Открыть |
| `Backspace`, `Alt+←` / `Alt+→` | Назад / вперёд |
| `Alt+↑` | В родительскую папку |
| `Alt+Home` | Домашняя папка |
| `Ctrl+L`, `Alt+D` | Ввести путь (`Tab` — дополнение) |
| `Ctrl+H` | Показать скрытые файлы |
| `Ctrl+A`, `Esc` | Выделить всё / снять выделение (`Esc` также закрывает меню и прерывает операцию) |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Копировать / вырезать / вставить в текущую папку |
| `F2` | Переименовать |
| `Ctrl+Shift+N` | Новая папка |
| `Delete` | В корзину (в корзине — удалить насовсем) |
| `Shift+Delete` | Удалить насовсем (с подтверждением) |
| `Ctrl+Z` | Отменить последнюю операцию |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Повторить отменённое |
| `Ctrl+F` | Поиск по имени в папке и вложенных (`Esc` — выйти) |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | Вид: значки / подробно / компактный |
| `←` / `→` | В виде значков — соседняя плитка |
| `F5`, `Ctrl+R` | Обновить |
| `Ctrl+I` | Нижняя панель: анализ места и свойства |
| `Alt+Enter` | Открыть панель для выделенного («Свойства») |
| `Ctrl+Q`, `Ctrl+W` | Закрыть окно |

## Устройство

```
src/
├── dir.rs       содержимое папки, сортировка, даты
├── mime.rs      типы файлов по shared-mime-info
├── icons.rs     поиск иконок по теме freedesktop
├── places.rs    «Места» и «Устройства»: XDG-папки, закладки GTK, разделы
├── watch.rs     слежение за папкой через inotify
├── devices.rs   диски и флешки через UDisks2: подключение, извлечение, сигналы
├── notify.rs    уведомления org.freedesktop.Notifications
├── settings.rs  канал `files` единого KDL-конфига (conchy-config)
├── analysis.rs  сводка по папке и точечное обновление дерева анализа
├── apps.rs      «Открыть с помощью»: .desktop, mimeapps.list, запуск
├── search.rs    поиск по имени в фоне
├── thumbs.rs    миниатюры по спецификации freedesktop
├── uca.rs       пользовательские действия из files.kdl
├── remote.rs    сетевые адреса через FUSE (sshfs, rclone)
├── instance.rs  одиночный экземпляр: сокет и протокол запросов
├── fm1.rs       org.freedesktop.FileManager1 («Показать в папке»)
├── cache.rs     дисковый кеш анализа: формат, UUID раздела, лимит размера
├── ops.rs       операции с файлами, конфликты, отмена
├── trash.rs     корзина по спецификации freedesktop.org
├── scan.rs      параллельный обход ФС (для анализа места)
├── model.rs     плоское дерево узлов, статистика по типам
├── treemap.rs   алгоритм squarified treemap
├── layout.rs    раскладка карты
├── ui/
│   ├── mod.rs       окно: состояние, навигация, выделение, клавиши
│   ├── view.rs      панель пути, боковая панель, список, строка состояния
│   ├── actions.rs   команды, контекстные меню, фоновые операции
│   ├── panel.rs     нижняя панель: treemap, типы, крупные файлы, свойства
│   ├── devices.rs   «Устройства» в боковой панели
│   ├── network.rs   «Сеть»: подключение адресов, пароль, отключение
│   ├── openwith.rs  открытие программой по умолчанию, «Открыть с помощью»
│   ├── search.rs    поиск Ctrl+F
│   ├── grid.rs      виды «Значки» и «Компактный», миниатюры
│   ├── dnd.rs       перетаскивание
│   ├── dialogs.rs   диалоги и меню
│   └── field.rs     поле ввода
└── main.rs
```

Ядро не зависит от интерфейса и покрыто тестами: `cargo test`.

## План

Подробно — в [docs/thunar-port.md](docs/thunar-port.md): что из Thunar переносим, что заменяем компонентами Conchy, что не нужно.

| Этап | Что входит |
| :--- | :--- |
| 1 | Окно, боковая панель, путь, список, история, inotify, корзина, операции (готово) |
| 2 | Нижняя панель: treemap, типы, крупные файлы; свойства и предпросмотр файла (готово) |
| 3 | Устройства через UDisks2, уведомления, `FileManager1`, одиночный экземпляр (готово) |
| 4 | Виды значками и компактный, миниатюры, поиск, перетаскивание, повтор (готово; вкладок нет) |
| 5 | «Открыть с помощью», права, пользовательские действия в `files.kdl` (готово) |
| 6 | Сеть через FUSE: `sftp://`, `smb://`, `ftp://`, WebDAV (готово, проверено тестами; MTP и хранение паролей — нет) |
