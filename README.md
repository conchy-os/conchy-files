# conchy-files

Файловый менеджер для **Conchy OS**: интерфейс и поведение Thunar, переписанные на Rust и [GPUI](https://www.gpui.rs/), плюс анализ занятого места (treemap и типы файлов, как в WizTree).

> Статус: идёт перенос Thunar, этап 1 из 6 (см. [docs/thunar-port.md](docs/thunar-port.md)). Окно, навигация, список, корзина и операции с файлами работают. Анализатор диска возвращается на этапе 2 в виде нижней панели.

## Возможности

- **Окно как у Thunar.** Кнопки «назад», «вперёд», «вверх», «домой»; путь кнопками, по `Ctrl+L` — поле ввода с дополнением по `Tab`. Боковые кнопки мыши тоже листают историю.
- **Боковая панель.** «Места»: домашняя папка, рабочий стол, корзина, закладки GTK (общие с Thunar и Nautilus), иначе XDG-папки. «Устройства»: файловая система и смонтированные разделы с полоской занятого места.
- **Список.** Колонки «Имя», «Размер» (у папок — число элементов), «Тип» (описание из shared-mime-info), «Изменён» («Сегодня, 10:41»). Сортировка щелчком по заголовку, папки сверху, естественный порядок чисел. Иконки из темы freedesktop. Скрытые файлы по `Ctrl+H`, поиск по первым буквам.
- **Живое обновление.** Папка перечитывается через inotify, когда в ней что-то меняется.
- **Корзина** по спецификации freedesktop: та же, что у Thunar и `gio trash`. Восстановление, удаление насовсем, очистка.
- **Операции, как в Thunar.** Копировать, вырезать, вставить, переименовать, создать папку или файл, в корзину, удалить насовсем. Отмена через `Ctrl+Z`. Конфликты имён: заменить, пропустить, переименовать, объединить папки, «для всех». Операции идут в фоне с прогрессом и отменой.
- **Контекстные меню** для файлов и для пустого места, выделение `Ctrl`/`Shift`+щелчком, «Открыть терминал здесь».

## Скорость анализа

Сканер для нижней панели. Домашняя папка: 867 тыс. файлов, 96 тыс. папок, 194 ГБ, NVMe.

| | Время |
| :--- | :--- |
| `conchy-files`, первый запуск (холодный кеш) | 5.9 с |
| `conchy-files`, повторный запуск | 0.4 с |
| `du -sx ~`, повторный запуск | 1.8 с |

Замерить у себя: `cargo run --release --example scan_bench -- ~/`

## Сборка и запуск

Нужны Rust (stable) и системные библиотеки для GPUI: `wayland`, `libxkbcommon`, `libxcb`, `fontconfig`, `freetype2`, `vulkan-icd-loader`, а также `clang` и `cmake`.

```bash
git clone https://github.com/conchy-os/conchy-files.git
cd conchy-files
cargo run --release -- ~/Документы   # папка или файл; по умолчанию домашняя
```

В `Cargo.lock` зафиксирована `libc` 0.2.188: крейт `xattr` 0.2.3, который тянет GPUI 0.2.2, не собирается с `libc` 0.2.191. Не запускайте `cargo update` целиком, обновляйте пакеты по одному.

## Настройки

conchy-files входит в единый KDL-конфиг Conchy OS ([conchy-config](https://github.com/conchy-os/conchy-config)), канал `files`: файл `~/.config/conchy/files.kdl`. Он создаётся при первом запуске с комментариями; другие файлы (`wm.kdl`, `session.kdl`) программа не трогает.

```kdl
view {
    show-hidden false        // Ctrl+H; conchy-files saves it here
    folders-first true
    sort-by "name"           // name, size, type, modified
    sort-order "ascending"   // ascending, descending
    folder-size "items"      // items: "12 items"; none: faster on huge folders
}
window {
    width 1100
    height 720
    sidebar-width 210
}
terminal {
    command ""               // "Open Terminal Here"; empty: $TERMINAL or auto
}
theme {
    icon-theme ""            // empty: same as GTK apps
    font-size 13
}
```

- Изменения применяются сразу, без перезапуска: правка в редакторе, `conchy-config set files view.sort-by size` или любой настройщик через D-Bus `org.conchy.Config`.
- Окно само запоминает `Ctrl+H` и сортировку по щелчку на заголовке. Запись идёт через демон, чтобы остальные программы получили `PropertyChanged`; если демон не запущен — прямо в файл, комментарии сохраняются.
- Ошибка в файле не ломает окно: остаются прежние настройки, в строке состояния видно, что не так.

Для сборки `conchy-config` должен лежать рядом: `../conchy-config`.

## Клавиши

Как в Thunar 4.20.

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓`, `Shift+↑` / `Shift+↓` | Перемещение и расширение выделения |
| `Home` / `End`, `PageUp` / `PageDown` | В начало / конец списка, на страницу |
| `Enter`, двойной щелчок | Открыть |
| `Backspace`, `Alt+←` / `Alt+→` | Назад / вперёд |
| `Alt+↑` | В родительскую папку |
| `Alt+Home` | Домашняя папка |
| `Ctrl+L`, `Alt+D` | Ввести путь (`Tab` — дополнение) |
| `Ctrl+H` | Показать скрытые файлы |
| `Ctrl+A`, `Esc` | Выделить всё / снять выделение (`Esc` также закрывает меню и прерывает операцию) |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Копировать / вырезать / вставить в текущую папку |
| `F2` | Переименовать |
| `Ctrl+Shift+N` | Новая папка |
| `Delete` | В корзину (в корзине — удалить насовсем) |
| `Shift+Delete` | Удалить насовсем (с подтверждением) |
| `Ctrl+Z` | Отменить последнюю операцию |
| `F5`, `Ctrl+R` | Обновить |
| `Ctrl+Q`, `Ctrl+W` | Закрыть окно |

## Устройство

```
src/
├── dir.rs       содержимое папки, сортировка, даты
├── mime.rs      типы файлов по shared-mime-info
├── icons.rs     поиск иконок по теме freedesktop
├── places.rs    «Места» и «Устройства»: XDG-папки, закладки GTK, разделы
├── watch.rs     слежение за папкой через inotify
├── settings.rs  канал `files` единого KDL-конфига (conchy-config)
├── ops.rs       операции с файлами, конфликты, отмена
├── trash.rs     корзина по спецификации freedesktop.org
├── scan.rs      параллельный обход ФС (для анализа места)
├── model.rs     плоское дерево узлов, статистика по типам
├── treemap.rs   алгоритм squarified treemap
├── layout.rs    раскладка карты
├── ui/
│   ├── mod.rs       окно: состояние, навигация, выделение, клавиши
│   ├── view.rs      панель пути, боковая панель, список, строка состояния
│   ├── actions.rs   команды, контекстные меню, фоновые операции
│   ├── dialogs.rs   диалоги и меню
│   └── field.rs     поле ввода
└── main.rs
```

Ядро не зависит от интерфейса и покрыто тестами: `cargo test`.

## План

Подробно — в [docs/thunar-port.md](docs/thunar-port.md): что из Thunar переносим, что заменяем компонентами Conchy, что не нужно.

| Этап | Что входит |
| :--- | :--- |
| 1 | Окно, боковая панель, путь, список, история, inotify, корзина, операции (готово) |
| 2 | Нижняя панель: treemap, типы, крупные папки; свойства и предпросмотр файла |
| 3 | Устройства через UDisks2, уведомления, `FileManager1`, одиночный экземпляр |
| 4 | Виды значками и компактный, миниатюры, поиск, вкладки, повтор действия |
| 5 | «Открыть с помощью», свойства и права, пользовательские действия в `files.kdl` |
| 6 | Сеть через FUSE (`sftp://`, `smb://`, MTP) |
