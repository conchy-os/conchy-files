# conchy-files

Быстрый файловый менеджер для **Conchy OS**, который сразу показывает, что и сколько места занимает. Дерево папок, статистика по типам файлов и treemap на одном экране, как в WizTree.

Написан на Rust, интерфейс на [GPUI](https://www.gpui.rs/).

> Статус: ранний прототип (0.1). Работает просмотр и анализ диска, операций с файлами пока нет.

## Возможности

- **Быстрое сканирование.** Параллельный обход на всех ядрах. Не переходит на другие файловые системы, не следует по символическим ссылкам, жёсткие ссылки считает один раз.
- **Дерево папок.** Доля от родительской папки (полоска с процентом), размер, число файлов. Крупное всегда сверху.
- **Типы файлов.** Сколько места занимает каждое расширение. Хвосты версий схлопываются: `libfoo.so.12` считается как `.so`. Клик по типу подсвечивает его на карте.
- **Treemap.** Площадь ячейки равна размеру, у каждого типа свой цвет. Вложенные папки подписаны, мелочь собирается в блок «ещё N».
- **Всё связано.** Клик по ячейке карты раскрывает дерево до этого файла. Двойной клик по папке открывает её на карте, «хлебные крошки» сверху возвращают назад.
- **Управление с клавиатуры.**

## Скорость

Домашняя папка: 867 тыс. файлов, 96 тыс. папок, 194 ГБ, NVMe.

| | Время |
| :--- | :--- |
| `conchy-files`, первый запуск (холодный кеш) | 5.9 с |
| `conchy-files`, повторный запуск | 0.4 с |
| `du -sx ~`, повторный запуск | 1.8 с |

Замерить у себя: `cargo run --release --example scan_bench -- ~/`

## Сборка и запуск

Нужны Rust (stable) и системные библиотеки для GPUI: `wayland`, `libxkbcommon`, `libxcb`, `fontconfig`, `freetype2`, `vulkan-icd-loader`, а также `clang` и `cmake`.

```bash
git clone https://github.com/conchy-os/conchy-files.git
cd conchy-files
cargo run --release -- ~/        # путь к папке; по умолчанию домашняя
```

В `Cargo.lock` зафиксирована `libc` 0.2.188: крейт `xattr` 0.2.3, который тянет GPUI 0.2.2, не собирается с `libc` 0.2.191. Не запускайте `cargo update` целиком, обновляйте пакеты по одному.

## Клавиши

| Клавиша | Действие |
| :--- | :--- |
| `j` / `k`, `↓` / `↑` | Вниз / вверх по дереву |
| `l` / `h`, `→` / `←` | Раскрыть / свернуть папку |
| `Enter` | Показать папку на карте |
| `Backspace` | Карта на уровень вверх |
| `o` | Открыть через `xdg-open` |
| `F5` | Пересканировать |
| `q`, `Ctrl+Q` | Выход |

## Устройство

```
src/
├── scan.rs      параллельный обход ФС
├── model.rs     плоское дерево узлов, статистика по типам
├── treemap.rs   алгоритм squarified treemap
├── layout.rs    раскладка карты: вложенность, подписи, группировка мелочи
├── ui.rs        окно на GPUI
└── main.rs
```

Ядро (`scan`, `model`, `treemap`, `layout`) не зависит от интерфейса и покрыто тестами: `cargo test --lib`.

## План

| Версия | Что входит |
| :--- | :--- |
| 0.1 | Сканер, дерево, типы файлов, treemap, клавиатура (готово) |
| 0.2 | Поле ввода пути, заполнение дерева во время сканирования, поиск |
| 0.3 | Операции с файлами: копировать, переместить, переименовать, корзина, отмена |
| 0.4 | Кеш индекса между запусками, обновление через `inotify` |
| 0.5 | Предпросмотр файлов, вкладки |
| далее | Конфиг `~/.config/conchy/files.kdl`, пакет в `conchy-packages`, интеграция с `conchy-shell` |
