# Перенос Thunar на Rust

conchy-files повторяет интерфейс и поведение Thunar 4.20, но написан заново на Rust и GPUI
под Conchy OS: Void без systemd, Wayland, конфиг на KDL через `conchy-config`, уведомления
через `conchy-shell`. Анализ места (treemap, типы файлов) переезжает в нижнюю панель.

Код Thunar служит образцом поведения (GPL-2.0-or-later, совместима с GPL-3.0-or-later проекта).

## Что не переносим

| Компонент Thunar | Почему |
| :--- | :--- |
| `thunar-session-client` | Сеансы X11; сеанс ведёт `conchy-session` |
| `thunarx` и бинарные плагины | Расширение через пользовательские действия в KDL |
| `thunar-tpa`, `thunar-wallpaper` | Нужны xfce4-panel и xfdesktop |
| `thunar-sendto-email`, `thunar-apr` | Свойства и метаданные показывает нижняя панель |
| `thunar-terminal-widget` (VTE) | Достаточно «Открыть терминал здесь» |
| `thunar-emblem-chooser` | Эмблемы живут в метаданных gvfs |
| D-Bus `org.xfce.*` | Остаётся только `org.freedesktop.FileManager1` |
| Редакторы порядка меню, панели, колонок | Порядок задаётся в `~/.config/conchy/files.kdl` |
| `thunar-preferences` (xfconf) | Канал `files` в `conchy-config` (уже подключён) |
| GIO и gvfs | Без GLib: локальная ФС напрямую, сеть через FUSE (sshfs, rclone), диски через UDisks2 |

## Решения по интеграции

- Уведомления: `org.freedesktop.Notifications` по D-Bus (сервер в `conchy-shell`, есть кнопки-действия).
  Сокет `conchy-shell.sock` не используем: незнакомая строка там открывает лаунчер.
- Иконки: тема freedesktop из `gtk-3.0/settings.ini` (по умолчанию Adwaita), типы файлов — shared-mime-info.
- Корзина: своя реализация спецификации freedesktop (`trash.rs`), общая с другими программами.

## Этапы

| Этап | Что входит | Статус |
| :--- | :--- | :--- |
| 1 | Окно как у Thunar: боковая панель «Места» и «Устройства», панель пути (кнопки и `Ctrl+L`), вид списком с сортировкой, история, скрытые файлы, inotify, корзина, операции, контекстные меню | готово |
| 2 | Нижняя панель: treemap, типы, крупные файлы; для файла — свойства и предпросмотр; дисковый кеш анализа | готово |
| 3 | Устройства через UDisks2 (подключение, извлечение, сигналы), уведомления, `FileManager1`, одиночный экземпляр, `.desktop` и D-Bus-активация | готово |
| 4 | Виды значками и компактный, миниатюры (кеш freedesktop), поиск `Ctrl+F`, перетаскивание, повтор `Ctrl+Shift+Z` | готово, кроме вкладок |
| 5 | «Открыть с помощью» (`.desktop`, `mimeapps.list`), права в свойствах, пользовательские действия в `files.kdl` | готово |
| 6 | Сеть через FUSE: `sftp://` (sshfs), `smb://`, `ftp://`, `dav(s)://` (rclone), пароль по запросу | готово, проверено только тестами |

### Что сознательно иначе, чем планировалось

- **Нет «вечного» фонового процесса.** GPUI 0.2.2 под Wayland останавливает цикл событий, когда закрыто последнее окно. Вместо `thunar --daemon`: один процесс, пока открыто хоть одно окно, и запуск по требованию через D-Bus (`--service`). Удержание деревьев анализа с PSI стало не нужно — их возвращает дисковый кеш за ~0.2 с.

### Не сделано

- Вкладки и разделение окна (`F3`).
- Зашифрованные разделы (LUKS) в «Устройствах».
- Хранение паролей сетевых папок (Secret Service), MTP-телефоны.
- Массовое переименование (`thunar-sbr`) — отдельной утилитой.
- Вид и сортировка не запоминаются между запусками: для этого нужно поле в схеме `files` в conchy-config (новый pull request).
